# Python Foundations

This folder contains my Python learning exercises as part of a Data Analytics Bootcamp focused on water data analysis and hydrological data.

The goal of this section is to build a strong foundation in Python programming before moving into data analysis, data visualization, and geospatial analysis.

The exercises in this folder focus on fundamental programming concepts that are essential for working with environmental and water-related datasets.

---

## Topics Covered

The following Python concepts are practiced in this section:

- Python basics
- Variables
- Data types
- Basic mathematical operations
- User input
- Simple hydrology-related examples

These concepts form the foundation for future data analysis tasks.

---

## Folder Structure

Day01.py

Introduction to Python fundamentals including:

- Printing output using `print()`
- Creating and using variables
- Understanding data types
- Performing basic calculations
- Receiving input from the user

Hydrology-related examples are used such as rainfall values and river discharge to simulate real-world environmental data.
