# Data Analytics Lab

This repository documents my journey toward becoming a **Water Data Analyst** using Python, data analysis tools, and geospatial technologies.

My goal is to develop strong technical skills for analyzing environmental and hydrological data, while building a professional portfolio of projects.

---

## Focus Areas

The main focus of this repository includes:

- Python programming
- Data analysis
- Hydrological data analysis
- Water resources data analysis
- Geospatial data analysis
- Environmental data processing

---

python-foundations

topics include:
- variables
- data types

- user input
- introductory hydrology examples

projects

This folder will contain complete data analysis projects related to water systems and environmental datasets.

Examples of future projects:

- river discharge analysis

weekly-data-challenges

Weekly data analysis exercises designed to strengthen problem-solving and analytical thinking.
